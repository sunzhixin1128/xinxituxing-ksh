# 03 统计图形分析

用于拆解信息图形案例中承担统计表达的图形。先查清一行数据代表什么、一个标记又代表什么，再追踪两者之间的计算与编码。同一张信息图可包含几个统计图形，每个图形单独记录。

- [01 RAWGraphs 统计图形拆解方法](01-RAWGraphs统计图形拆解方法.md)给出源码阅读顺序、案例记录模板与聚合示例。
- [02 字段、计算与图形对照](02-字段计算与图形对照.md)对照条形图、折线图、箱线图、气泡图、六边形分箱图、矩形树图、冲积图和桑基图等 9 种实现。
- [03 案例演示 · Fortune 500 都会区营收](03-Fortune500都会区营收统计拆解.md)从成图反查统计单元、聚合、分母和编码，再给出可核验的重制方案。
