# 02 主题内容分析

与大模型讨论选题，记录选题背景、已有材料、候选方案、选择依据和待核实项。

| 判断维度 | 讨论内容 |
| --- | --- |
| 数据逻辑 | 主要按时间推进可考虑编年型，主要按对象或属性分类可考虑编目型，也可按材料判断是否适合层级型、字母表型或地理图形。 |
| 视觉风格 | 根据内容、受众和素材条件，比较平面图形、照片风格及其组合。 |
| 类型标签 | 关键词及其权重可考虑词云型，条目及说明可考虑文字列表型，照片承担主体信息时可考虑图片式。 |

记录主数据逻辑、视觉风格和适用标签，并写明它们分别服务的读图任务。模型提出的事实回到原始来源核实。

## 先确定读图任务

按《信息图形设计导论》第 31–44、86 页，把选题改写成目标读者能够回答的问题。从查找具体值或对象、比较差异、理解信息如何组织、辨认变量间的关联四类任务来检查方案。选出一个主要任务，写下读者完成它所需的背景知识与数据字段。然后比较两种表现方式，说明各自给读者增加或减少了哪些查找与计算步骤。

用「主题与受众 → 读图任务 → 主要数据关系 → 表现形式与选择依据」写出方案摘要。数据逻辑、表现形式标签与视觉风格分别记录。课件第 48–67 页讨论数据架构，第 68–84 页用案例展示常用表现形式。 [案例分析与论述框架](../../02-信息图形类型案例/案例索引.md#案例分析与论述框架)
