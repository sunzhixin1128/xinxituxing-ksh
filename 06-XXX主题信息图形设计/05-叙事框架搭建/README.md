# 05 叙事框架搭建

从基础数据集中选取能够共同回答一个问题的字段。按读者的阅读顺序，记录每个叙事模块的问题、使用字段、要传达的信息及配套图形。

| 字段组合 | 叙事内容 |
| --- | --- |
| 地点名称 + 纬度 + 经度 | 在地图上标出地点并标注名称 |
| 地点名称 + 统计年份 + GDP + GDP 单位 | 说明某地某年的 GDP，比较多地时核对年份、单位及统计口径 |

产出为分镜或版面草图，注明各模块如何从概览推进到比较和细节。


## 让概览、比较和细节接得上

参考《信息图形设计导论》第 89、110–117 页。先让读者看到主题、指标和范围，再通过共同的比较尺度或有依据的排序看到差异，最后给出支持差异的具体数据、局部图或注释。用编号、直标、引线或一致的类别标记把层次接起来，便于读者从重点返回原有上下文。

| 层次 | 分镜要交代的内容 |
| --- | --- |
| 概览 | 主问题是什么？哪组数据或图形作入口？ |
| 比较 | 用哪些字段和统一口径显示差异？可直接从版面读出什么？ |
| 细节 | 哪条记录、哪个时间段或哪个区域支持这一判断？读者如何找到它？ |

检查每个视觉模块是否承担证据、定位或解释功能。删减装饰时保留必要的尺度、单位、标签及来源。由图观察到的差异和解释差异的补充证据，在分镜中各自注明出处。
