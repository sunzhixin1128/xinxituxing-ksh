# 信息图形研究与案例库

以五种数据组织逻辑建立分类，从实际案例归纳统计方法、视觉编码和叙事经验。

## 五种基础数据逻辑

| 主类型 | 核心信息关系 | 定义文档 |
| --- | --- | --- |
| 编年型 · Chronologically | 按时间、阶段或事件先后组织 | [01 编年型](01-信息图形数据逻辑/01-编年型信息图形概念定义.md) |
| 层级型 · Hierarchically | 按上下位、包含和从属关系组织 | [02 层级型](01-信息图形数据逻辑/02-层级型信息图形概念定义.md) |
| 编目型 · Categorically | 按对象类别与属性分组 | [03 编目型](01-信息图形数据逻辑/03-编目型信息图形概念定义.md) |
| 字母表型 · Alphabetically / Index-based | 依字符或明确检索键排列 | [04 字母表型](01-信息图形数据逻辑/04-字母表型信息图形概念定义.md) |
| 地理图形 · Geographically | 按位置、区域和空间联系组织 | [05 地理图形](01-信息图形数据逻辑/05-地理图形信息图形概念定义.md) |

按作品主导的信息关系选择一种基础主类型。混合型、时间轴、词云等表现标签用于检索案例，可以并用。01 的定义按 A 数据逻辑、B 统计图形与计算、C 视觉编码、D 数据与信息架构、E 视觉叙事架构编排。

## 案例录入与回写

先核对原图和来源，再判断基础主类型与表现标签。记录读图任务、数据结构、统计口径、视觉编码和论述证据。形成可复用的结论后，再补到相应定义与案例索引。字母表型课件案例仍待核验其字符排序规则。 [案例录入与知识回写规范](02-信息图形类型案例/案例录入与知识回写规范.md) · [案例索引](02-信息图形类型案例/案例索引.md)
