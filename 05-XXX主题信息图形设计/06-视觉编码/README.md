# 06 视觉编码

将叙事模块写成可执行的设计表达。记录每个视觉元素承载的字段、阅读作用、样式与标注方式。

| 设计要素 | 实践内容 |
| --- | --- |
| 点、线、面、体 | 例如果用点标记地点、用线表示路线、用面划分区域，应明确位置、长度、面积或体积各自承担的含义。 |
| 色彩 | 明确分类色、数值渐变与重点强调色的用途。 |
| 字体与排版 | 定义标题、正文和注释的层级，设置行距、字距和对齐方式。 |
| 图像与图形 | 记录照片、插图、示意图的作用、裁切和标注方式。 |
| 统计图形 | 根据比较、趋势或构成等任务选择图形，核对刻度、单位和图例。 |
| ISOTYPE 图形 | 使用重复图符表达数量时，标明单个图符对应的数量。 |

产出为视觉编码表、样式规范与代表性版面草图。
