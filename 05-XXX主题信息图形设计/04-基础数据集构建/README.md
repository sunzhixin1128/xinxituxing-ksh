# 04 基础数据集构建

一行对应一个明确的观察对象或记录。一列只对应一个字段，每个单元格只存一个值。字段可存名义类别、量化数值、单张图像的路径或链接，或一条文本。

| 示例字段 | 数据类型 |
| --- | --- |
| 地点名称 | 名义数据 |
| 纬度 | 量化数据 |
| 经度 | 量化数据 |
| 统计年份 | 年份 |
| GDP | 量化数据 |
| GDP 单位 | 单位 |
| 图片路径 | 图像引用 |
| 地点说明 | 文本 |

经度和纬度分列，数值和单位分列。同一对象关联多张图片时，用对象 ID 和图片路径建立关联表，每行记录一次关联。

产出为基础数据表和字段说明，注明每列的含义、类型、单位、来源及缺失值表示。
