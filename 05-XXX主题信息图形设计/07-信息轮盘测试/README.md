# 07 信息轮盘测试

依据冯白帆《信息图形设计导论》第 39–44、88、91–102、115–117 页，先记录方案的表达取舍，再用读图任务验证。以下为仓库的实践记录方法，课件中的轮盘示例用于讨论设计取舍。

1. **记录取舍。** 逐项说明设计更偏抽象还是具象、实用还是修饰、致密还是稀疏、多维还是单维、创新还是通用、简洁还是保留辅助信息。每项写明理由，并指出该选择可能影响的读图任务。
2. **做对照验证。** 为当前稿和改动稿设置相同的读图题。请读者找出主题、读出数值、比较变化，或指出事实与作者解释各在哪里。记录正确性、用时、查找路径及误读位置。课件第 39 页用限时找变化的练习体现查找成本，实际测试可按作品和受众设定时限。
3. **记录调整。** 若读者在图例、位置对应或统计口径处反复停顿，标记具体问题，调整后用相同任务再测。按需要测试延迟记忆，并注明间隔和条件。
