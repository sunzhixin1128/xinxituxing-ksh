# 三主题调用样例

以对话中《财富》500 强都市圈营收图的青灰底、纽约白色圆、图外标注和定位引线为作品级参考。这里选择三条形式规则建立演示档案 fortune-callouts v1.0。地图、城市与营收值属于原题材。三个新主题均为教学示意，标注由本示例设定。交付范围为提示词，图像验收状态为 not_generated。

## 通用模板

用 {{subject}} 替换主体，用 {{setting}} 替换底层结构，用 {{focus_label}} 指定原样保留的强调标签，用 {{reading_task}} 指定阅读任务。固定 S1–S3，画幅在这组实例中锁定为 3:4。

## 带变量的通用四版

### 中文 JSON

```json
{
  "style_id": "fortune-callouts",
  "style_version": "1.0",
  "style": [
    {
      "id": "S1",
      "priority": "must",
      "instruction": "用低饱和青灰底衬托深墨色标记，留一个白色焦点。"
    },
    {
      "id": "S2",
      "priority": "must",
      "instruction": "以细引线将主体位置对应到外围标签，每条线可单独追踪。"
    },
    {
      "id": "S3",
      "priority": "must",
      "instruction": "次级元素减弱对比，标签清晰直标。"
    }
  ],
  "subject": "{{subject}}",
  "environment": "{{setting}}",
  "narrative": "{{reading_task}}",
  "mood": "克制、清晰",
  "technical": {
    "format": "3:4",
    "literal_labels": [
      "{{focus_label}}"
    ]
  },
  "constraints": [
    "保留标签原文，标记大小不表示数量。"
  ]
}
```
