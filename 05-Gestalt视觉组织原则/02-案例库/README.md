# 37 组 Gestalt 视觉组织案例

图源为用户提供的《Gestalt格式塔视觉组织.zip》。按原始 01–37 编号记录 37 组案例，共 38 个原始图片文件。G01 为原 JPG 中的双图拼版，G01B 为同编号但画面不同的 PNG。标题优先采用画面可见的文字，其余为便于检索的描述。原发布出处以图片内可见署名为线索，待进一步核查。

主分类按作品中最容易核实、最能解释整体阅读方式的线索确定。辅助线索指同图也能观察到的其他组织方式。部分静态图的鱼群朝向可以提示方向，判定共同运动或同步仍需要画面变化的时间证据。每张图片与分析存入独立 CASE 档案，规则页通过案例索引关联。

## 从案例迁移到信息图形

- **先建立参照，再突出例外。** G03、G07、G16 与 G24 都保留整组的重复样式，只在一个对象上改变姿态、眼镜、明度或轮廓。用在统计图时，可以维持类别的共同样式，同时给要点加区别明显的标记与标签。 [G03 人形阵列](CASE-0003/分析.md#g03) · [G24 水滴与灯泡](CASE-0024/分析.md#g24)
- **区分边界、空隙与连线的作用。** G29 的色带限定元素属于哪一区，G35 的局部轮廓让读者补出一个对象，G37 的系线把两个对象直接连在一起。设计信息图时，先写清要表达的是区域归属、同一物件还是两对象间的关系，再选择对应线索。 [G29 蓝带](CASE-0029/分析.md#g29) · [G35 面包](CASE-0035/分析.md#g35) · [G37 气球与人物](CASE-0037/分析.md#g37)
- **双义图形适合引题，也需要验证可读性。** G14 与 G19 的双重读法来自共享边缘。用在信息图标题区时，可以用遮住标题的测试检查两层形是否可辨，在数据区优先给数值、单位和对应对象保留清晰标注。 [G14 刀与侧脸](CASE-0014/分析.md#g14) · [G19 街巷与酒瓶](CASE-0019/分析.md#g19)
