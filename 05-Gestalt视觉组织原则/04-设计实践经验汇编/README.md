# 14 案例分析与实践记录模板

| 字段 | 记录内容 |
| --- | --- |
| 案例与版本 | 标题、图源、作者或机构、原图链接、版本或日期 |
| 阅读任务 | 读者要找出、比较或判断的内容 |
| 数据依据 | 数据的分类、顺序或关系，核对其与读图任务的对应 |
| 适用规则 | 规则编号与名称 |
| 视觉线索 | 标记、距离、边界、连线、颜色或时间变化所在位置 |
| 设计分析 | 线索如何支持任务，哪些线索可能冲突 |
| 设计调整 | 调整项、对照版本及保持一致的条件 |
| 验证方法 | 读者任务、观察方式、是否记录正确率和误读位置 |
| 验证结果 | 实际观察、适用条件与未验证问题 |
| 实践经验 | 可迁移做法、局限、是否需要复验 |

先写下原图可见事实，再写可能的感知效果。缺乏读者验证时，将结论标为设计推断并保留验证计划。
