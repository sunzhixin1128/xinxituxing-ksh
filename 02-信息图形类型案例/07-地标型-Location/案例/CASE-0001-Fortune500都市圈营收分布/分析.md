# Fortune 500 都会区营收信息图

## 01 数据逻辑归类 · 地理图形信息图形

原图用企业总部所在都会区作为统计单元。每家上榜企业先按总部归入都会区，再计算该区上榜企业的累计营收。地图保留所有符合门槛的都会区位置，并把累计营收最高的十五个都会区单独标注。地图回答「总部集中在哪里」，营收排名回答「哪些都会区的上榜企业营收规模最大」。移除地理位置后仍可比较金额，但无法判断总部的空间分布。营收名次是空间汇总后的比较字段。见[地理图形信息图形概念定义](../../../../01-信息图形数据逻辑/05-地理图形信息图形概念定义.md)。

## 02 表现形式标签 · 混合型信息图形（Mixed Charts）

作品组合地图定位点、营收圆标、数值标签、跨区引线和编辑正文。地图提供覆盖范围与方位，圆标提示量级，直接标签支持精确比较，正文解释总部迁入和跨都会区合计。地图小点以一个都会区为单位，门槛是该区至少有一家上榜公司总部。它们表达空间存在性。见[混合型信息图形说明](../../../01-混合型-Mixed-Charts/00-标签说明.md)。

图源为用户提供的《Power Centers of the Fortune 500》，刊载于 *Fortune* 2020 年 6—7 月号第 200 页。信息图署名 Nicolas Rapp，正文署名 Brian O’Keefe。以下制作步骤依据成图和正文还原可复用的方法，原作者使用的软件与圆标标定方式尚未核实。

## 视觉编码

| 元素 | 对应数据或作用 | 制作取舍 |
| --- | --- | --- |
| 美国地图轮廓与周边地理形状 | 空间参考与方向感 | 降低周边地理形状的对比度，突出主要点位。重制时保持地理位置在投影下的相对关系。 |
| 地图上的小点 | 达到入图门槛的都会区 | 除重点引线外保留统一点样式。把「每点是一个都会区」写进地图内图注。 |
| 地图上方的大圆 | 前十五个都会区的营收量级 | 大圆移到独立排版区，在地理密集处仍能保留标签。原图未给出面积或直径的数值换算，准确读数取自标签。 |
| 白色圆和白色引线 | 首位纽约的视觉强调 | 让圆与引线共用强调色，读者可以沿同色线追到地图落点。其他圆使用一致的深色。 |
| 引线 | 将版面标记接回对应的地理点 | 曲率由避让与追踪需求确定。线长、交叉与方向没有独立的数值含义。 |
| 都会区名及金额 | 识别对象并精确比较 | 名称用较重字重，金额靠近名称。差距很小的相邻名次依靠金额标签区分。 |
| 右上角图表题和地图内图注 | 定义排名指标、对象层级与点的含义 | 图表题给比较范围，地图内图注就近说明点所代表的统计对象。 |

原图采用「位置点留在地图，比较符号移出地图」的布局。它为上方圆标保留了空间，也增加了跨图追线的成本。美国东北部等落点密集的区域最需要检查线条末端和交叉处能否逐条追踪。

## 视觉叙事

1. 顶部的大白圆和纽约金额先建立比较基准。周围的深色圆再引导读者观察达拉斯、芝加哥等其他高营收都会区。
2. 引线把上方的营收比较接回地图。小点将视野从获选标注的前十五名扩展到全部满足门槛的都会区。
3. 底部正文用 McKesson 总部从旧金山迁往得克萨斯州解释达拉斯排名的背景，再切换到圣何塞、西雅图和旧金山的跨都会区比较。总部计入地的变化可以影响榜单归属，单张图无法量出这一迁移造成的净增额。
4. 纽约圈标为 1.775 万亿美元，占全榜单营收的 12.5% 是正文口径。三个科技中心的圈标合计为 2.0423 万亿美元，与正文按万亿美元保留两位小数的 2.04 一致。跨区合计可高于纽约，纽约仍是单个都会区排名首位。

## 制作方法与流程

| 步骤 | 操作 | 交付或校验 |
| --- | --- | --- |
| 1 明确比较对象 | 确定榜单期次、收入字段、总部取值时间、都会区边界口径与地图覆盖范围。保留原始金额、币种和单位，另建标准化金额列。 | 一份口径说明，分别记录榜单出刊期和数据对应年度。 |
| 2 建立企业表 | 每家企业一行，分别登记企业 ID、总部地、都会区 ID、营收、币种、单位和来源。核对重复企业、迁址记录和未匹配总部。 | 一份可回查的企业明细。只有图片时，以圆标转录为起点，未公布的企业或地理点明细保持缺失。 |
| 3 汇总与排名 | 以都会区 ID 分组，标准化营收求和，企业 ID 去重计数。先保留全部合格都会区，再按累计营收降序选取前十五名。 | 一份制图汇总表，每行一个都会区。核对汇总额、前十五名与全榜单份额的分母。 |
| 4 生成地理图层 | 为每个都会区选取统一口径的代表点并保存经纬度。可用 QGIS 叠加点位和底图，分别导出底图、点位及前十五名作为矢量图层。 | 点位和边界有可追溯的来源。高密度区域缩放检查时不误把相邻城市接到同一引线。 |
| 5 构建比较图层 | 在地图上方分配圆标和标签位置。制作可定量读取的版本时，以圆面积与营收成正比，令半径为参考半径乘以营收与参考营收之比的平方根，并给出尺寸图例。 | 各圆使用同一面积比例。纽约用色彩提高辨识度。相近量级保留直接金额标签。 |
| 6 布设引线和文字 | 在矢量排版工具中按都会区 ID 把大圆连回小点，调整曲线控制点。少量交叉不可避免时，让交角更清楚，并为线端与相邻文字留出空间。 | 从每个圆正向追到点，再从重点区域逆向追到圆。核对都会区名和金额没有串位。 |
| 7 编排正文并导出 | 依次安放首位对比、总部迁移背景和跨区比较。统一显示精度，注明数据口径、图源和署名。按成品尺寸检查字号、对比和印刷或屏幕效果。 | 可编辑矢量稿和发布图。用底表复核全部标签，确认圆面积、点位、引线与正文采用各自明确的含义。 |

当重点是精确比较营收，可在同一页配一张零基线条形图，保留地图用于空间定位。当前图像足以核对圈标及正文数值，未标名点的都会区身份、公司数量与营收仍缺少明细。
