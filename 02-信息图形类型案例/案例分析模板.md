# 案例分析模板

| 项目 | 记录内容 |
| --- | --- |
| 读图任务与来源 | 标题、作者、出版日期或链接、媒介、目标受众与问题 |
| A 数据逻辑 | 基础主类型、最小观察单位、字段与关系 |
| B 统计图形与计算 | 分组、计量单位、聚合口径、分母与尺度 |
| C 视觉编码 | 字段如何映射到位置、长度、色彩、图符或其他视觉通道 |
| D 数据与信息架构 | 表格字段、关联键、主辅模块与证据来源 |
| E 视觉叙事架构 | 阅读入口、比较顺序、图注、结论与局限 |
| 表现标签与迁移 | 可检索的表现标签、可尝试的设计方法与读图验证 |

每个判断附图中证据，区分原图可见、转录、计算、推断及待核事项。 [案例索引与论述框架](案例索引.md#案例分析与论述框架)
