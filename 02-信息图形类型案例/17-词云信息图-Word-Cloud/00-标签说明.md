# 词云型信息图形（Word Cloud）

## 01 数据逻辑归类 · 编目型信息图形

常见的单幅词云将词或短语汇总为可识别的条目。每个唯一词条有一个显示名称和一个权重，还可带主题或来源字段。权重决定该条目在视图中的视觉显著程度，词条仍可回查到语料。以时间分组并按时间顺序组织多幅词云时，整页可采用编年逻辑，各幅图内部仍是词条汇总。见[编目型信息图形概念定义](../../01-信息图形数据逻辑/03-编目型信息图形概念定义.md)。

## 02 表现形式标签 · 词云型信息图形

词云把词条文字直接用作图形标记，以字号映射词频、文档频次或其他非负权重。它适合为演讲、访谈、评论或开放题回答提供主题概览，并引导读者回到语境核对。本文为类型分析，具体作品的语料、频次口径和编码需按原图逐项核验。

## 数据与统计图形

| 字段 | 用途 |
| --- | --- |
| 词条 ID | 把同一规范词条的不同显示形式接回汇总记录 |
| 显示词条 | 存放在词云中排版的词或短语 |
| 词频 | 该词条在清洗后语料中的出现次数 |
| 文档频次 | 至少出现一次该词条的文档数 |
| 制图权重 | 实际传给字号比例尺的非负数值 |
| 主题类别 | 在完成分类且设有图例时作为颜色字段 |
| 语料组 | 区分来源、时间段或其他对比样本 |
| 语料引用 | 连接到原文 ID、检索结果或附表中的上下文 |

词频衡量重复出现的次数。文档频次衡量覆盖范围，例如同一篇文章重复出现十次对文档频次只贡献一次。统计短语时需写明短语与组成词是否会同时计入。不同大小的语料组可按每千个清洗后词元计算标准化词频，也可按各组文档数计算文档覆盖率。TF-IDF 是可选的相对权重，需要记录参考语料、具体公式和跨文档聚合口径，图注使用相应指标名称。

## 视觉编码

| 元素 | 对应数据或作用 | 制作取舍 |
| --- | --- | --- |
| 文字标记 | 词条名称 | 统一字体与字重，保留短语内部的分词关系，确认字体覆盖所需字符。 |
| 字号 | 所选权重 | 在可读范围内设置同一比例尺。采用对数或其他压缩时注明映射，字形面积还会受字数、字形和字体影响。 |
| 色彩 | 经定义的主题类别，或少量重点词的强调 | 颜色承担数据含义时提供图例，同一类别使用一致颜色。装饰色只承担版面作用。 |
| 位置与间距 | 排版和避让，或另有明确定义的分区 | 普通排布中的靠近、居中和方向不提供共现、语义距离或数值排名。若用明确分区编码类别，应标出边界和含义。 |
| 旋转与轮廓 | 阅读方向或版面约束 | 优先保持水平，中文竖排需检查读序。使用外轮廓时，应检查长词和低权重词的可读性。 |
| 外部数值标签或附表 | 原始数量、标准化值和来源 | 精确比较时提供按权重排序的表或条形图，让读者核对同字号与近似权重。 |

## 信息架构与视觉叙事

标题先交代语料来源、取样范围及统计口径。读者从高权重词进入，再扫读次级词条，最后通过排序表或原文摘录查证。导读可以突出某个主题，但需要说明编辑挑选的依据。高频只表明在指定规则下反复出现。语气、否定、发言者立场与词间关系需要结合原文或独立的共现分析判断。

## 制作方法与流程

| 步骤 | 操作 | 交付或校验 |
| --- | --- | --- |
| 1 定义问题 | 选择语料范围、统计单位和指标，记录纳入规则。 | 明确要回答的是重复出现、文档覆盖还是组间差异。 |
| 2 清洗文本 | 按语言分词，统一大小写或异体写法，确定停用词、专名和多词短语。保留原文和规则记录。 | 抽查歧义词、否定词和可能被拆开的专名。 |
| 3 汇总权重 | 用词条 ID 分组计算词频或文档频次。若比较语料组，统一分母口径和预处理。 | 导出一词条一行的表，依据阈值或前若干名筛选并记录并列处理规则。 |
| 4 排布词云 | 设置字号区间、字体、色彩规则、画布和旋转约束，按权重依次放置文字并做碰撞检测。 | 记录参数和随机种子，如工具支持。比对输入与成图，记录未放入画布的词条。 |
| 5 标注与核验 | 补充标题、单位、来源和过滤说明。跨组并排时共享字号比例尺及颜色含义。 | 抽查原文与底表，确认同权重同字号、近值可查、实际尺寸可读。 |
