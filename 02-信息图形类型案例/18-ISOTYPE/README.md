# ISOTYPE

ISOTYPE 在本仓库中是可以跨类型使用的基础设计方式标签。它用经过简化和标准化的图形符号传达统计信息。案例可沿用自己的数据逻辑与表现形式分类，同时标注 ISOTYPE。

## 标签判定

- 先确认图标代表的对象和计量单位。以重复符号编码数量时，同一比较口径采用等大的图标，每个完整图标代表固定数量，数值差异通过重复次数表达。
- 在图例中说明单位和不足一个完整图标时的处理方式。例如，一枚图标代表 10 人，25 人可用两枚半图标表示，前提是图例说明半枚代表 5 人。
- 同一比较中保持单位、符号样式和排列一致。颜色若用于区分类别或状态，给出对应图例。需要精确读取时附数值。
- 仅作栏目提示、插画或装饰的图标没有固定计量含义。证据不足时，先记录图例或符号换算待核验。
