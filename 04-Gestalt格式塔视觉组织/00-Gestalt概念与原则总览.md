# Gestalt 概念与原则总览

格式塔视觉组织原则解释读者如何把局部标记看成组、轮廓、主体和背景，以及如何感知整体形态。对于信息图形，先明确数据中实际存在的类别、顺序与关系，再选择能够支持这些关系的视觉线索。

## 数量说明

文献没有公认的固定总数。本目录有 **12 份编号 01–12 的原则专题**，另有一份依据课件补充的[视觉组织线索专题](16-边界对比与视觉情境.md)。先前总览的 13 项知识点保留，元素连接与均一连接合写在一份文档，广义共同命运放在共同命运一节。综述将图底组织与分组分别讨论，良好形态涉及整体组织。 [Wagemans 等，2012，视觉组织综述](https://elderlab.yorku.ca/wp-content/uploads/2016/12/WagemansPsychBull12.pdf) · [Van Geert 与 Wagemans，2024，良好形态原则综述](https://pubmed.ncbi.nlm.nih.gov/37787874/)

| 编号 | 专题 | 定义 |
| --- | --- | --- |
| 01 | [接近原则](01-接近原则-Proximity.md) | 在其他条件相近时，空间距离较近的元素更容易被知觉为一组。 |
| 02 | [相似原则](02-相似原则-Similarity.md) | 颜色、形状、大小或朝向相近的元素更容易被组织在一起。 |
| 03 | [良好连续原则](03-良好连续原则-Good-Continuation.md) | 沿相近平滑方向延伸的边缘或线段，容易被组织为连续轮廓或路径。 |
| 04 | [闭合原则](04-闭合原则-Closure.md) | 接近围成封闭轮廓的片段容易形成一组。有时即使轮廓不完整，读者也会感知一个完整形状。 |
| 05 | [共同区域原则](05-共同区域原则-Common-Region.md) | 位于同一个可感知边界或容器内的元素容易被看成一组。 |
| 06 | [连接原则](06-连接原则-Connectedness.md) | **元素连接**指独立元素借接触、共享边界或可见连线形成一组。**均一连接**指相连且颜色、亮度或纹理等属性一致或平滑变化的区域容易被看成一个单元。 |
| 07 | [共同命运原则](07-共同命运原则-Common-Fate.md) | 以相近方式移动的元素容易被视为一组。广义共同命运还包括亮度等属性的同向变化。 |
| 08 | [同步原则](08-同步原则-Synchrony.md) | 可见变化在同一时刻发生时，元素可能被看成一组，变化方向可以不同。 |
| 09 | [对称原则](09-对称原则-Symmetry.md) | 具有镜像对称关系的边缘或部件容易被组织成一个形状。 |
| 10 | [平行原则](10-平行原则-Parallelism.md) | 平行或近似平行的边缘、线段或轨迹容易被看成一组。 |
| 11 | [图底组织](11-图底组织-Figure-Ground.md) | 视觉将场景的部分区域组织为有形状、拥有共享边界的主体，周围区域作为背景。 |
| 12 | [简洁与良好形态原则](12-简洁与良好形态原则-Pragnanz.md) | Prägnanz 描述知觉在给定条件下趋向形成较稳定、容易把握的整体组织。简洁是可能的组织特征之一。 |
